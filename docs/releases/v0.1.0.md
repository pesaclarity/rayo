# rayo 0.1.0

The first release of rayo: on-device inference in plain C89, for C, Dart and Flutter. A
general runtime for small models, a graph of 41 ops over a plain-weights file, with a
converter for TFLite, ONNX and Hugging Face language models, and small language models in
little memory.

## Highlights

- **Plain C89 and nothing else.** No C++, no other library, nothing downloaded or prebuilt:
  `package:rayo`'s build hook compiles it from source for Android, iOS, macOS and Linux, so
  F-Droid builds it offline.
- **The best kernels for the CPU, chosen at run time:** SSE4.1, AVX2 and AVX-VNNI on x86;
  NEON, the dot product (SDOT) and int8 matrix multiply (i8mm) on ARM. The same floats, bit
  for bit, from every kernel, thread count and compiler.
- **Small language models in little memory:** 4-bit weights with float16 scales (some
  3-bit if asked), an int8 key/value cache, prompts in chunks, the tokeniser's table read from
  the mapped file, a sampler and a generator, and the model's chat template, all in C. A
  135M-parameter chat model holds about 15 MB of its own memory at 1000 tokens.
- **Untrusted models and text:** every size and offset checked, limits on what a file can
  make rayo allocate, typed errors and never a crash; fuzzed, sanitised and statically
  analysed in CI; and SHA-256 and Ed25519 signature checks before a model is read.
- **Zero allocations per run,** and weights mapped from the file.
- **Tested everywhere it builds:** Linux x86_64, arm64 and armv7, macOS on Apple silicon and
  Intel, iOS (device and simulator, the tests in a simulator), Windows (MSVC and clang-cl),
  the Android NDK builds (about 191 KB for arm64-v8a), and the Dart package.

## Getting it

- **Dart and Flutter:** `dart pub add rayo`, or
  `rayo: {git: {url: https://github.com/pesaclarity/rayo.git, ref: v0.1.0}}`.
- **C:** the source archive below, or `git clone --branch v0.1.0
  https://github.com/pesaclarity/rayo.git`; [docs/GETTING-STARTED.md](https://github.com/pesaclarity/rayo/blob/v0.1.0/docs/GETTING-STARTED.md)
  has a 20-line quickstart.
- **rayo-convert:** `pip install "rayo-convert @ git+https://github.com/pesaclarity/rayo@v0.1.0#subdirectory=convert"`.

## Prebuilt model

`smollm2-135m-instruct-q4.weights`: [SmolLM2-135M-Instruct](https://huggingface.co/HuggingFaceTB/SmolLM2-135M-Instruct)
by Hugging Face, converted by rayo-convert 0.1.0 to 4-bit weights with float16 scales and a
2048-token context, with its tokeniser's table and chat template in the file. It is the
model's work under the **Apache License 2.0**, not rayo's: its licence and notice are the
`.LICENSE.txt` and `.NOTICE.md` assets next to it. Check it with
`sha256sum -c smollm2-135m-instruct-q4.weights.sha256`, then:

```sh
make && ./examples/chat/chat smollm2-135m-instruct-q4.weights
```

## Benchmarks

The numbers in the README come from GitHub's shared x86_64 and arm64 runners and one core of
a 2.1 GHz Xeon, each labelled as such. No phone has been measured yet: `tool/bench_phone.sh`
measures one over adb ([docs/PERFORMANCE.md](https://github.com/pesaclarity/rayo/blob/v0.1.0/docs/PERFORMANCE.md)).
